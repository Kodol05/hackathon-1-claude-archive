# Club Activity Tracker (동아리 활동 기록 관리 웹앱)

2026-08-05 해커톤 프로젝트

## 팀원 명단과 역할
| 이름 | 역할 |
|---|---|
| 박재웅 | 아이디어 기획, 보고서 작성 (개발 미참여) |
| 김현민 | GitHub 저장소 관리, CLAUDE.md 작성, 공통 저장 함수, 필수 기능 - 활동 등록 |
| 이정호 | 필수 기능 - 활동 목록 조회 및 삭제 |

1단계(필수 기능)는 김현민·이정호 2명이 개발한다. 기능 단위로 분담하며, 각자 자신이 맡은 기능의 HTML·CSS·JS를 끝까지 구현하고 기능 단위로 커밋한다.

## 구현 기능

### 필수 기능 (1단계, 김현민·이정호 담당)
- [ ] 공통 저장 함수: getActivities / saveActivities / generateId (김현민)
- [ ] 활동 등록: 입력 폼 + 검증 + 저장 (김현민)
- [ ] 활동 목록 조회: 최신순 표시, 빈 목록 안내 (이정호)
- [ ] 활동 삭제: 확인 절차 포함 (이정호)
